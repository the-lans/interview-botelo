# Каталог фронтенд-тестов (Dashboard)

## 1) UI smoke
- Рендер всех ключевых секций Dashboard.
- Пустое состояние блока прогресса.
- Базовая доступность основных кнопок и полей.

## 2) Пользовательский флоу
- Обработка вакансии из raw text.
- Генерация плана после заполнения обязательных данных.
- Logout и редирект на страницу входа.

## 3) Валидация формы
- Ошибка при попытке обработать вакансию с пустым вводом.
- Блокировка кнопки генерации без обязательных полей.
- Корректная смена состояния кнопок во время операций.

## 4) Компонентные сценарии
- Ветка 401 при загрузке прогресса (показ ссылки на login).
- Ветка ошибки ingest (показ алерта ошибки).
- Ветка fallback-рендера результата плана как JSON.

## Реализовано в этой итерации
- `tests/dashboard.test.tsx`: покрывает пункты 1–4 выше.
- Добавлены сценарии редиректа на login при `401` и silent refresh прогресса после генерации плана.
